# v0.7.14 性能优化与验证

已实现按需预览提前停止、文件版本与编码/列起点缓存、原始样本复用、同工作簿复用、两路预览读取与过期队列跳过；预览只渲染可见行列，字段列表每页 100 组且搜索覆盖所有页。字段分组缓存、筛选预编译、相似字段候选索引、进度节流和精确去重内存预算共同减少重复计算。筛选/去重选项不再请求不变的输出计划。

不增加自动内容样例。生产保留默认 XLSX 压缩，日期格式复用；低压缩实验收益不足，未上线开关。两种现有合并模式、独立来源改名、文件格式和数据库 COPY 保持兼容。

复测入口：`npm run validate -- --postgres --performance --large --output /tmp/sheetforge-validation`。详见 [脚本说明](../scripts/performance/README.md)。本地检查为 Rust 103 项、前端 55 项行为加 16 项结构、真实 PostgreSQL 17 的 8 项集成用例；格式、Clippy、构建和审计通过，审计仍有 14 条既有允许警告。

以下测量使用提交前候选的 Release 测试程序，普通路径与正式版一致；压缩对照仅存在于 `cfg(test)`。候选源码快照、原始 575 次阶段记录和浏览器结果保留在本次交付的验证包中。首次完整统计仍需读全表；后台逐步返回表头、跨重启元数据复用、编译档位以及远程 PostgreSQL 批次调优未纳入本轮发布，不对这些环节作提速承诺。

## 压缩实验（未上线）：时间与体积

| 场景 | 普通 ms | 快速 ms | 时间变化 | 普通/快速 MiB |
|---|---:|---:|---:|---:|
| csv_1m_16 | 12681.08 | 12220.47 | -3.6% | 83.49 / 103.20 |
| xlsx_inline_10k_512 | 6896.81 | 6322.84 | -8.3% | 21.64 / 28.72 |
| xlsx_numeric_edges_100k_64 | 8124.81 | 7670.08 | -5.6% | 27.11 / 37.52 |

低压缩的完整导出仅快 3.6%–8.3%，文件增大约 24%–38%，未达到本轮 10% 的明显收益门槛，所以生产界面不增加开关，保留默认压缩。实验仅由 cfg(test) 入口启用，两种压缩的工作表/样式 XML 与读回内容均一致。精确去重使用 64 MiB 键预算，超过后落本机临时索引；这会增加部分场景耗时，不能描述为所有去重都更快。完整明细与超过 10% 的变化见 summary.csv。

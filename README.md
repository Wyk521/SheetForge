# SheetForge 表格工坊

一个面向 Windows 的现代原生 GUI 工具，用来批量合并 Excel / CSV 数据。使用 Rust + Slint 开发，不依赖 Python、不依赖浏览器内核，也不上传数据。

## 下载 Windows 成品

从 [Releases](https://github.com/Wyk521/SheetForge/releases/latest) 直接下载并运行 `SheetForge.exe`，无需解压。

## 已实现功能

- 递归扫描文件夹，也支持一次选择多个文件。
- 读取 `.xlsx`、`.xlsm`、`.xls`、`.xlsb`、`.ods`、`.csv`、`.tsv`。
- 一个工作簿中的每个非空 Sheet 都可单独勾选。
- 每个数据表可单独选择表头所在行；调整后自动重新读取字段和数据行数。
- 三种表头策略：
  - **并集**：保留所有出现过的列。
  - **交集**：只保留每张已选表都存在的列。
  - **手动映射**：以并集为基础，为写错或含义相同的列填写统一目标列名；可隐藏无需修改的共有字段。
- 可追加“来源文件”和“来源工作表”两列，方便追溯。
- 超过 XLSX 的 1,048,576 行限制时，自动创建 `合并结果_002`、`合并结果_003` 等 Sheet；每个 Sheet 都保留表头。
- CSV 自动识别逗号、Tab、分号、竖线分隔，兼容 UTF-8 与常见 GBK 中文文件。
- 合并在后台执行，界面实时显示进度并可取消。
- XLSX 写出使用恒定内存模式，适合大数据文件。

## 直接构建 Windows 版本

在 Windows 10/11 上安装 [Rust](https://rustup.rs/) 后，右键用 PowerShell 运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build-windows.ps1
```

构建完成后：

- 可执行文件：`target\release\SheetForge.exe`
- 可直接分发的程序：`dist\SheetForge.exe`

也可以把项目推到 GitHub，打开 **Actions → Build Windows**，运行后下载构建产物。

## 使用方法

1. 选择一个文件夹或多个表格文件。选择文件夹时会递归扫描全部子目录。
2. 在数据表列表中取消不需要的 Sheet；若表头不在第一行，可为该表调整“表头行”。
3. 选择“并集”“交集”或“手动映射”。
4. 手动映射时只需处理列名差异，例如把 `手机号`、`联系电话` 都改为 `电话`；共有字段可一键隐藏。
5. 选择输出位置，点击“开始合并”。

## 合并规则细节

- 自动匹配会去除表头首尾空格，并忽略英文大小写。
- 空表头会命名为 `未命名列1`；重复表头会自动添加 `_2`、`_3`。
- 手动模式中，如果同一张表有多个源列映射到同一目标列，会取该行第一个非空值。
- Excel 公式读取的是工作簿中保存的计算结果，不会把原公式复制到输出文件。
- 输出只包含单元格值，不复制原文件的样式、图片、图表、批注或宏。

## 项目结构

```text
ui/
  app-window.slint  现代桌面界面与自适应布局
src/
  app.rs      Slint 交互桥接、后台任务状态
  scan.rs     递归发现文件、读取表头、CSV 编码与分隔符处理
  model.rs    并集/交集/手动映射的数据模型
  merge.rs    行映射、恒定内存 XLSX 写出、自动拆分 Sheet
  main.rs     Windows 程序入口
```

## 隐私与兼容性

所有处理都在本机完成。程序不发起网络请求。首次运行未签名的自行构建版本时，Windows SmartScreen 可能显示提醒；商业分发时建议为 EXE 添加代码签名。界面使用 Slint，其许可要求的归属信息位于应用的“关于”对话框中。
